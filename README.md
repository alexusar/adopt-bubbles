# The Department of Whale Affairs 🐳

An engagement gift and official (entirely fictional) adoption experience for Bubbles, a Warmies whale born August 30, 2026, and his adoptive parents Dana Garcia and Jonathan Lopez.

## Local preview

Open `index.html` in a browser. No build step or external dependencies.

## Deployment

Merge the pull request, then enable GitHub Pages: **Settings → Pages → Deploy from a branch → main / (root)**. The expected URL is `https://alexusar.github.io/adopt-bubbles/` once Pages is enabled and deployment succeeds.

## Privacy and signatures

Signatures are handled locally in the browser and included in the downloaded certificate. The site does not upload signatures or collect payment. The $1/month and other obligations are jokes. Please use the downloaded certificate to preserve the signed copy.

Photos of Bubbles are used with permission from the gift-giver. Replace `assets/bubbles-*.jpg` to update the gallery.
